Udaipur Sports Project Analysis
================================

Project Name: Udaipur Sports
Type: React + Vite storefront / sports e-commerce mock website
Purpose: Premium sports gear shopping experience for Udaipur athletes and sports enthusiasts.

1. Project Overview
-------------------
This project is a front-end React application that mimics a modern sports retail website. It includes:
- Home screen
- Product catalog
- Product detail page
- Cart and checkout UI
- Category filtering
- Wishlist and notifications
- Responsive navigation and marketing-focused design

The app is built around a premium dark theme with green accent colors and a strong sports-brand identity.

4. Key Files and Their Purpose
------------------------------

package.json
- Defines dependencies and scripts
- Scripts include:
  - npm run dev
  - npm run build
  - npm run preview
  - npm run lint

vite.config.ts
- Configures Vite React plugin and Tailwind plugin
- sets simple aliasing and dev server rules

index.html
- Contains app root and Google Fonts imports
- Bootstraps the app through /src/main.tsx

src/main.tsx
- Entry point of the app
- Calls ReactDOM.createRoot and renders <App />

src/types.ts
- Contains TypeScript interfaces used across app
- Product
- CartItem
- ScreenType

src/data.ts
- Contains the product catalog and static cart items
- This is the main data source for the storefront

src/App.tsx
- Main brain of the app
- Manages all major app state:
  - current screen
  - active product
  - cart items
  - wishlist
  - notifications
  - filters
  - checkout form
  - pricing
- Controls screen navigation and business logic

src/components/Header.tsx
- Fixed top navigation bar
- Includes brand name, category links, search input, cart icon, and mobile menu

src/components/Footer.tsx
- Footer content
- Department links
- Newsletter subscription form
- Payment badge UI

src/components/Notification.tsx
- Toast notification system for success/info/error alerts
- Animated popups with icons and dismissal button

src/index.css
- Tailwind import
- custom theme colors and font tokens
- utility classes for glow and gradient effects

7. Cart and Pricing Logic
-------------------------
The cart supports:
- item quantity management
- selected size per cart item
- subtotal calculation
- free shipping
- promotional discount
- GST calculation
- total value generation

Example pricing logic:
- subtotal = sum(product.price * quantity)
- shipping = 0
- discount = if promo applied then 15%
- taxes = 18% on discounted subtotal
- total = subtotal - discount + taxes

10. Real App Behavior Summary
----------------------------
This is not a real backend-powered store. It behaves like a polished frontend demo or mock storefront.

It uses local in-memory state to simulate:
- product selection
- category browsing
- filtering
- cart operations
- checkout form data
- notification flows

11. Important Observations
-------------------------
- The project is heavily UI-focused.
- Data is static and defined in code instead of being fetched from a real database or API.
- It is built as a prototype for a premium sports shopping brand.
- The app includes AI-related packages but the current UI does not demonstrate a working AI backend.
- It is designed like a marketing storefront and product catalog rather than a production e-commerce backend.

12. Conclusion
--------------
This project is a modern React-based sports e-commerce mockup created for Udaipur Sports. It uses a premium design system, product-driven data, dynamic filtering, cart logic, notification feedback, and responsive storefront behavior. It showcases how a product catalog app can be organized with React, TypeScript, Tailwind, and animation libraries.
